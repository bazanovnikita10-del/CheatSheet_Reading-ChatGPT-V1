## 📖 Суть проекта

Это компактная электронная шпора в прозрачном корпусе, которая выглядит как обычный брелок или маленький гаджет.  
Внутри — **ESP32-S3 Super Mini** с OLED-дисплеем, тремя бесшумными кнопками и аккумулятором на 300 мАч.

> 🚀 **Это самая первая электронная шпаргалка из всех, у которой есть полноценный чат с нейросетью прямо на устройстве!**  
> (версия от 09.11.2026)

### 🧠 Что умеет шпора:

- **Шпаргалки** — список текстовых файлов (можно загружать через веб-интерфейс)
- **Точка доступа Wi-Fi** — для управления файлами с телефона
- **Мини-игры**:
  - Google Динозаврик
  - Flappy Bird
  - Змейка
- **Чат с нейросетью** (ProxyAPI / OpenAI) прямо с клавиатуры на экране
- **Настройки**:
  - регулировка яркости
  - режим «левши» (переворот экрана и смена кнопок)
  - монитор заряда батареи
  - сброс до заводских настроек

### 🎮 Управление

- **Короткое нажатие** — навигация, выбор
- **Долгое нажатие** — выход / дополнительное действие

## 🚀 Как прошить

1. Установите **Arduino IDE** (рекомендуется 2.3.x)
2. Установите ядро **ESP32** (Boards Manager)
3. Установите библиотеки:
   - `GyverOLED`
   - `ArduinoJson`
   - `LittleFS` (встроенная)
4. Выберите плату **ESP32S3 Dev Module**
5. Настройки:
   - Flash Size: **4MB (32Mb)**
   - Partition Scheme: **Huge APP (3MB No OTA/1MB SPIFFS)**
   - PSRAM: **Disabled**
6. Прошейте скетч из папки `main/`
